Integration Notes

This demo collects the customer subdomain and product before rendering the embedded messaging widget. Metadata is attached via conversation fields so agents can see which channel application the request originated from. The widget renders in embedded mode using zE('messenger', 'render', { mode: 'embedded', ... }).
